# Changelog

## [0.2.0] - 2026-08-29

### Changed

- Replaced the flat Phase 1 map presentation with original pixel-art village and town backgrounds.
- Added a readable original adventurer sprite, map landmarks, atmosphere, and clearer portal/NPC presentation.
- Refined the game HUD hierarchy, zone-entry banner, panel contrast, and mobile safe-area layout.
- Recorded generated asset provenance in `assets/asset-manifest.json`.

## [0.1.0] - 2026-08-29

### Added

- Phase 1 Project Midgardia monorepo foundation.
- Express, Socket.IO, Prisma, and SQLite server.
- Account registration/login and persistent character creation.
- Server-authoritative movement, collision, portals, NPC dialog, and chat.
- Phaser 3 client with original procedural avatars, map rendering, HUD, minimap, responsive mobile controls, and keyboard shortcuts.
- Tiled-compatible map source, Docker Compose, CI workflow, and architecture notes.
